快速开始：从零到上架

  1. 注册市场账号：前往 开发者控制台 注册（email + 密码）。市场账号独立于店铺用户体系。
  2. 申请开发者：登录后在控制台提交开发者申请（简介 ≥20 字：作品/技术背景），平台审批通过后获得提交权限。
  3. 开发插件：一个目录两个文件——plugin.json（清单）+ index.js（ESM 入口，默认导出插件定义）。无需构建链，原生 Node 24 语法直接跑。
  4. 打包提交：zip 打平这两个文件（≤2MB），控制台上传提交，填写版本号与定价（免费 /onetime 买断）。
  5. 审核发布：先过自动检查（结构/安全扫描/语法），再人工审核。批准后平台 ed25519 签名发布——私钥仅在平台侧，开发者永不持签。
版本规则：published 版本不可覆盖；新版本走正常提交；被拒版本修复后可重提（覆盖原提交）。插件名全局先到先得。

包结构与 plugin.json 规范

my_plugin.zip
├── plugin.json     # 清单（必须）
└── index.js        # ESM 入口（默认；可在 entry 指定别名）
字段必填说明
name✓^[a-z][a-z0-9_]{2,49}$，与提交名一致，全局唯一先到先得
version✓semver 三段式（如 1.0.0），与提交版本一致
description建议≤500 字，市场列表展示
entry可选入口文件名，默认 index.js；须匹配 ^[a-zA-Z0-9_.-]+$
assets可选随包分发的附加文件数组（条目名进 zip 白名单校验）

硬性限制

项限制
zip 体积≤ 2MB（解压后 ≤ 8MB）
条目数1–64 个文件
路径禁止绝对路径 / .. / 白名单外字符（zip-slip 防护）

自动检查（auto_scan）披露清单

提交时全量静态扫描，不过门直接拒；以下模式不阻断但计入披露，供人工审核重点核对——请在文档/简介里说明用途：

模式审核关注点
process.env读取了哪些环境变量、用途
node:fs / fs文件读写范围（建议只读自身目录）
child_process基本会被拒，除非强需求
node:net原始套接字用途
http(s) / 外联 URLwebhook/上报类必须仅 https + 禁私网 + 禁重定向
eval / new Function动态代码执行，基本会被拒
入口文件会以 node --check 做语法校验。进程内信任模型（S1）：插件与 core 同进程运行，审核是安全主闸——详见仓库 SECURITY.md。

插件 API 参考

入口默认导出插件定义（纯对象，无需框架）：

export default {
  name: "my_plugin",
  version: "1.0.0",
  description: "一句话说明",
  configSchema: [ ... ],        // 可选：admin 配置表单（见下）
  activate(ctx) { ... },        // 启动加载时调用（重启生效，不热载）
  deactivate(ctx) { ... },      // 可选：停用清理
}

PluginContext（ctx）

成员说明
ctx.log(msg)日志（前缀 [plugin:名] 进 core 日志）
ctx.options.get/set(name, value?)gq_options 受控读写（配置即读即用）
ctx.query(sql, params)受控 SQL 执行器——必须 $n 参数化，禁止字符串拼接
ctx.bus.on(事件, handler)订阅事件总线（异常隔离，单插件失败不阻断主流程）
ctx.registerGoodsType(entry)注册商品类型（发货 handler 同事务）
ctx.registerPayPlugin(entry)注册支付方式（清单+下单校验）
ctx.registerRoute(route)自定义 HTTP 路由（method/path/handler，path 以 / 开头）
ctx.registerDashboardCard(entry)后台仪表盘卡片（数据三形态，插件不注入前端代码）

事件总线（13 事件）

事件payload 要点
core:init启动完成
order:createdorderId / outTradeNo / userId / amountCents
pay:settledorderId / gateway / amountCents / executor（同结算事务）
deliver:after / deliver:failedorderId / goodsType / contents|error
stock:lowgoodsId / stock（支付扣减后 ≤10）
user:registereduid / superior
aftersale:created / aftersale:refundedaftersaleId / orderId；退款单（executor 同事务，佣金反扣链）
station:opened / withdraw:reviewed分店开通 / 提现审核

配置表单（configSchema）

声明后 admin 插件页自动渲染表单，存 gq_options 的 plugin_config:{name}（JSON blob），键白名单+类型强制：

configSchema: [
  { key: "webhook_url", label: "Webhook URL（仅 https）", type: "string",
    placeholder: "https://…" },
  { key: "secret", label: "签名密钥", type: "password", hint: "留空不签名" },
  { key: "interval", label: "去抖秒数", type: "number" },
  { key: "enabled", label: "开关", type: "boolean" },
]

仪表盘卡片数据三形态

type结构
stats{ items: [{label, value}] } 指标卡
list{ columns: [], rows: [[]] } 表格卡
text{ text: "…" } 文本卡（空态友好）

卡片可加 perm: "aftersale.manage" 等权限位，无权限账号不渲染。

示例代码

最小插件（3 行激活）

export default {
  name: "hello_world", version: "1.0.0",
  description: "示例：订阅支付事件打日志",
  activate(ctx) {
    ctx.bus.on("hello_world", "pay:settled", (p) => {
      ctx.log(`收到支付 ¥${(p.amountCents / 100).toFixed(2)} order#${p.orderId}`);
    });
  },
}

公开路由插件（SEO / 回调类）

export default {
  name: "my_route", version: "1.0.0",
  activate(ctx) {
    ctx.registerRoute({
      method: "GET", path: "/my-plugin/hello",
      handler: (c) => new Response("hello from plugin", {
        headers: { "content-type": "text/plain; charset=utf-8" },
      }),
    });
  },
}

卡片插件（经营统计）

export default {
  name: "my_card", version: "1.0.0",
  activate(ctx) {
    ctx.registerDashboardCard({
      id: "today", title: "今日订单",
      load: async (q) => {
        const r = await q.query(
          "SELECT COUNT(*)::int AS cnt FROM gq_order WHERE create_time >= $1",
          [Date.now() - 86400000]);
        return { type: "stats", items: [{ label: "24h", value: r.rows[0].cnt + " 单" }] };
      },
    });
  },
}

SQL 一律 $n 参数化——拼接 SQL 会被审核直接拒绝。

付费与 license 机制

模型说明
free免费，直接安装
onetime买断（含后续升级），按插件+域名授权
svip店主侧订阅：月度 SVIP 覆盖全部付费插件

购买与授权流

  1. 店主在控制台购买：插件 + 店铺域名（licensee 即域名，license 与域名绑定，非账号）。
  2. epay 支付（MD5 验签+金额核对+幂等结算）→ 平台签发 license（JSON + ed25519 签名）。
  3. 控制台下载 {plugin}.lic → 店铺后台「插件管理 → 导入 license」（写入前完整复验：验签+域名匹配）。
  4. 安装/升级付费插件时内核校验 license（已装不回收，只挡新装与升级）。

license 生命周期

操作行为
重购限制同域名持有效授权（或 SVIP）时重复购买被拒（409）
作废（平台）附理由作废；已装实例不回收，解除重购限制
重签（平台）签名钥轮换配套：当前钥重签全部有效 license，店主重新下载
下架（平台）市场索引移除全部版本（zip 保留）；已装不回收；恢复=新版本过审

结算（平台抽成）

每笔成交落 market_sales_record：开发者净额 = 毛额 ×（1 − 平台抽成基点/10000），默认抽成 30%。控制台「我的收益」实时可查；平台侧月度 CSV 对账导出。

店主接入市场

  1. core 环境变量配置市场源：GQSHOP_MARKET_URL=https://license.sc9.top/repo
  2. 后台「插件管理 → 应用市场」浏览清单，安装/升级/回滚/卸载（重启 core 生效）。
  3. 每个包安装时内核自动双验签（sha256 哈希 + ed25519 签名），篡改即拒。
  4. 付费插件：先在 控制台 购买下载 .lic，再在插件页「导入 license」。
自建市场也行：GQSHOP_MARKET_DIR 指向本地目录（只读卷），格式与线上一致（market-index.json + zip）。
